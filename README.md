# ジェムクラフト (Gem Craft)

岩山で採掘し、石を磨いて指輪・ペンダント・ブレスレットに加工、注文やオークションで売る宝石クラフトゲームです。
ブラウザだけで遊べる単一HTMLアプリです（スマホ対応）。

## 遊び方

1. **⛏ 採掘** — 岩をタップして掘る。深い層ほど硬いけれど、いい石が出やすい。
2. **✨ 研磨** — タイミングゲームで石を磨く。うまく止めるほど品質アップ。
3. **💍 加工** — 宝石 × 形（指輪・ペンダント・ブレスレット・イヤリング）× 金属（銀・金・プラチナ）で作る。イヤリングは同じ宝石2個のペア。
4. **📜 注文** — お客さんの注文に合う品を納めると高く買ってくれる。
5. **🔨 競売** — 3日に1回のオークション。来場者の好みに合う品が高値になる。
6. **💰 売却 / 🔧 強化** — 毎日の需要を見て売る。稼いだお金で道具を強化（Lv10まで）。

体力は毎日限られています。宿屋の食事や、眠る場所（野宿・安宿・上等な部屋）で回復できます。

## 特徴

- 宝石20種（超レアのピンクダイヤ・パライバトルマリン・ブルーダイヤモンド・パパラチアサファイアを含む）と、最深層「星の核」
- 売上が貯まると王宮から依頼が届き、女王のティアラと王の王冠を作るエンディングへ（クリア後も遊べます）
- 宝石図鑑
- 修行モードで全部の強化をLv15にすると「工房の覚醒」（金色の演出）。さらに最終依頼「黄金の玉座」と、2つ目のエンディングが現れます
- 宝物庫（作った名品や図鑑を飾る部屋。図鑑がそろうほど豪華に）
- 難易度（やさしい／ふつう／むずかしい／修行）。途中で変更できます
- 同じ宝石を売り続けると相場が下がる、オークションの来場者には予算がある、など終盤の駆け引き
- レア度に応じた演出（効果音もすべてブラウザ内で合成）
- 外部通信なし・AI APIなし。セーブはブラウザの localStorage に保存されます

## 公開（GitHub Pages）

1. このリポジトリに `index.html` と `README.md` を置く
2. Settings → Pages → Branch を `main` / `(root)` にして Save
3. 数分後に `https://osenbeiandtea.github.io/gem-craft/` で遊べます
